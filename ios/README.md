# Progres na iPhone (instalacja z Maca)

Potrzebujesz: Maca z Xcode (darmowy, z Mac App Store), iPhone'a, kabla i Apple ID.

1. Otwórz `Progres.xcodeproj` w Xcode.
2. Xcode → Settings → Accounts → `+` → zaloguj się swoim Apple ID.
3. Kliknij projekt **Progres** po lewej → target **Progres** → zakładka **Signing & Capabilities** → w polu **Team** wybierz „(Twoje imię) (Personal Team)”.
   Jeśli pojawi się błąd o Bundle Identifier, zmień go na unikalny, np. `com.twojeimie.progres`.
4. Podłącz iPhone'a kablem i na telefonie stuknij „Ufaj temu komputerowi”.
5. Na iPhonie włącz **Ustawienia → Prywatność i ochrona → Tryb dewelopera**, telefon się zrestartuje.
6. W Xcode u góry wybierz swojego iPhone'a jako cel i naciśnij ▶ (⌘R).
7. Przy pierwszym uruchomieniu na iPhonie: **Ustawienia → Ogólne → VPN i urządzenia zarządzane** → Twój Apple ID → **Ufaj**.

Z darmowym Apple ID aplikacja działa 7 dni. Potem podłącz telefon i naciśnij ▶ jeszcze raz. Nie usuwaj aplikacji z telefonu, wtedy treningi zostają.

Treningi są zapisane tylko w aplikacji na telefonie. Kopię zapasową zrobisz w zakładce Miesiąc → „Pobierz kopię”.
